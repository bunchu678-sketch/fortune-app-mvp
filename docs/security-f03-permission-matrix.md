# 契約停止のアクセス制御：期待結果と未確定範囲

先生surfaceに限った新規利用の判定候補。実装・試験前に整理した期待値である。
本番B2Cは対象外、combinedの従来機能を維持する。adminは従来どおり鑑定/履歴/帳票を404。

| 状態 | 教室なし鑑定 | 教室付き鑑定・新規保存 | 対象履歴/人物の変更・削除・復元・再鑑定準備 | 新規Excel/PDF生成（発行済みtoken含む） |
| --- | --- | --- | --- | --- |
| 未ログイン | 404 | 401 | 401 | 401 |
| 本人・有効な生徒契約 | 404 | 当該教室だけ可 | 実履歴の所有者/教室/契約を照合して可 | 実履歴またはtokenに束縛された教室で判定 |
| 本人・有効な無料試用 | 404 | 当該教室だけ可 | 当該教室だけ可 | 当該教室だけ可 |
| 試用利用権を取り消した後 | 404 | 拒否 | 拒否 | 拒否 |
| 自主休止・未納休止 | 404 | 拒否 | 拒否 | 拒否 |
| 支払済み利用期間終了後 | 404 | 拒否 | 拒否 | 拒否 |
| 所属権限取消し | 404 | 拒否 | 拒否 | 拒否 |
| アカウント全体停止 | 404 | 401 | 401 | 401 |
| 先生 | 404 | 現在所属する教室で可 | 自分の履歴だけ | 自分の履歴/実行だけ |
| 運営管理者（所属なし） | 404 | 拒否 | 他人の履歴を拒否 | 他人の履歴を拒否 |
| 別教室の先生・生徒 | 404 | 他教室を拒否 | 他人の履歴を拒否 | 他人の履歴/tokenを拒否 |
| 複数教室に所属し一方だけ休止 | 404 | 有効な教室だけ可 | 履歴に記録された教室で判定。別教室で代用不可 | token/実履歴に記録された教室で判定 |

先生との提携終了は、生徒の有効契約を一括停止しない。先生本人の所属取消しは既存所属判定で拒否する。
試用終了の試験は合成DBで既存の利用権取消しを再現する。試用期限の新設や自動終了は対象外。
保存対象の教室は必須で、クライアントの指定だけを信頼しない。共有する人物/グループが別教室やB2Cにまたがる場合は変更を拒否する。
所有者を偽装したIDは404。入力不備は422、契約/利用権不足は403または既存の404、停止済みセッションは401。

## 閲覧方針は確定しない

履歴一覧/詳細/削除済み一覧/過去メモの本人閲覧は、既存の所有者SQLと`content_visible()`を維持する。
休止中/解約後/回復猶予の閲覧可否を新仕様として許可も拒否もしない。試験は既存挙動の観測と不変確認に留める。
他人の履歴を先生/運営者が通常閲覧できないことは、仕様未確定とは別に継続検証する。
候補検索は新規鑑定の補助なので現在の教室利用権を確認し、選択中教室の人物候補だけを返す。

現行の帳票APIは毎回新しくExcel/PDFを生成し、完成帳票を恒久保存していない。
したがって今回拒否するのは新規生成。過去の完成帳票を再配信する専用機能の可否を新たに決定しない。
出力tokenは本人/セッション/教室/有効期限に束縛し、発行後の契約変更も再確認する。
一回限りへの変更はせず、現行の有効期限内再利用/容量上限/再起動時消失を維持する。
