## 2名への利用案内（送信前の案）

- 公開先は既存先生URLを維持する計画。切替完了の連絡後、各自の既存メール/パスワードでログインする。他人のアカウントを共用しない。確認前に新しい招待やパスワード変更をしない。
- 入力→鑑定→入力に戻る/新しく鑑定する、4テーマ、ログアウトが利用できる。履歴保存・過去履歴・Excel/PDF・マイページ・教室管理は使えない。
- 新しい鑑定入力/結果は履歴へ保存しない。ブラウザーを閉じた後の入力・未保存結果をバックアップから復元することはできない。テーマと認証に必要な設定はサーバーに保存される。
- 既存履歴は削除しないが新画面から参照できない。必要な既存データの扱いは運営管理者へ相談する。取り出し操作は個別に認可する。
- 不具合は発生時刻・画面名・操作手順を運営担当へ伝える。パスワード、鑑定対象者の個人情報、sessionを含む画像を通常の報告に添えない。連絡先は本人が確定する。

- 最小保守は脆弱性修正、証明書/期限の確認、バックアップの定期受領・隔離復旧確認、空き容量/異常ログ、停止/失効対応。利用者拡大や販売の開発計画を追加しない。
